# 🕌 صلِّ قبل ما يفوتك - Prayer Face Verification

تطبيق جوال يُذكِّر المستخدم بمواقيت الصلاة، ولا يتوقف التنبيه إلا بعد **التحقق بالوجه**، مع **عداد يومي** للصلوات المؤداة.

---

## 📱 المميزات

- ✅ حساب مواقيت الصلاة حسب **الدولة والمدينة**
- ✅ إشعارات محلية مع **صوت الأذان**
- ✅ التحقق بالوجه باستخدام **الكاميرا**
- ✅ عداد يومي للصلوات المؤداة
- ✅ واجهة عربية بسيطة وجذابة
- ✅ حفظ الإعدادات محليًا

---

## 🛠️ التقنيات المستخدمة

| التقنية | الوظيفة |
|---------|---------|
| **Flutter** | تطوير التطبيق |
| **Google ML Kit** | التعرف على الوجه |
| **prayer_times** | حساب مواقيت الصلاة |
| **flutter_local_notifications** | الإشعارات المحلية |
| **shared_preferences** | حفظ الإعدادات |
| **image_picker** | التقاط الصور من الكاميرا |
